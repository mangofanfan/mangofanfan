## manifest.json 缓存

manifest.json 是 Minecraft 的版本清单文件，记载了一般启动器中可用的所有 Minecraft 版本。

MCLI 会缓存 manifest.json，缓存的有效期是当天。这可以避免重复获取 manifest.json 文件。

## 文件下载缓存

文件下载缓存包含库文件（libraries）和资源文件（assets）。

这些文件可能会跨版本通用，并且数量较多，大小不一。MCLI 借鉴包管理工具的普遍行为，在文件系统中建立这些文件的稳定缓存，并在以后获取相同文件时直接复用。

### 库文件

依赖库文件缓存在 `.mmccli/cache/libraries` 目录下。

库文件是 jar 文件，在 Java 中称之为库，命名一般为库名称和版本号。库文件位于 `.minecraft`
目录的 `libraries` 目录中，其存放位置一般为品牌域名逆向拼接的目录，下面是一些例子。

```text
.minecraft
⊢ libraries
  ⊢ com
    ⊢ google
      ⊢ code
        ⊢ gson
          ⊢ gson
            ⊢ 2.13.2
              ⊢ gson-2.13.2.jar
  ...
```

这些带有版本号的库是已经在 Gradle 中发布的，version.json 中会提供它们的 sha1 值用于校验，可以稳定缓存。

Forge 和 Fabric 模组加载器的有关依赖库文件也会在此缓存。

### 资源文件

散列资源文件缓存在 `.mmccli/cache/assets/objects` 目录下。

资源文件表现为以一串哈希值命名的无扩展名文件，形如 `0a9c7929a7ac1d4ade36b5a27dcdffbc6ed0bd74`，长度为 40。不难看出，这些资源文件的命名符合 sha1 哈希算法的十六进制输出结果，事实也正是如此。

这些资源文件存储在 `.minecraft` 目录的 `assets/objects` 目录中，并按照其文件名的前两位分目录存储。下面是一些例子。

```text
.minecraft
⊢ assets
  ⊢ objects
    ⊢ 0a
      ⊢ 0a9c7929a7ac1d4ade36b5a27dcdffbc6ed0bd74
      ⊢ 0a9d177aa4fb5896b3125f6aea8eadf62c7260dd
      ...
    ...
```

这些资源文件也会跨版本复用，并且内容可以根据文件名称校验，可以稳定缓存。

### 游戏本体

Minecraft 游戏本体会在 `.mmccli/cache/versions/client` 目录下缓存，以版本号命名。

### 模组加载器的安装器

Forge 安装器会在 `.mmccli/cache/forge-installer` 目录下缓存，MCLI 使用 Forge 安装器来安装 Forge。

Fabric 安装器不会缓存，因为 Fabric 安装比较简单，简单到 MCLI 安装 Fabric 的过程中并不会使用 Fabric 安装器。 

## 文件缓存方式

MCLI 的默认缓存复用行为是硬链接。

简单来说，硬链接在文件系统中表现为只占用一份存储空间的复数个文件，其数量称之为链接计数。为文件创建硬链接会使链接计数
+1，删除会使链接计数 -1，在计数归 0 时文件才会被真正删除，存储空间被释放。

MCLI 在 `~/.mmccli/cache/libraries` 和 `~/.mmccli/cache/assets` 中缓存库文件和资源文件，下载时的第一保存位置也是这里。在下载完成后，所有库和资源文件会在目标位置（即 MCLI 运行时指定的 `.minecraft` 中）创建硬链接。

::message{level=fan}
下载完成后，您可以放心清理 MCLI 的缓存，不会影响已安装的游戏的正常运行。但是这也意味着清理 MCLI 缓存对释放存储空间的效果可能有限。
::

**但是，并不是所有的文件系统都支持硬链接。**
例如，Windows 所推荐使用的 NTFS 仅支持同卷内部的硬链接，不允许跨卷硬链接，FAT32 和 exFAT
完全不支持硬链接等。这时，MCLI 会降级到从缓存复制文件到目标位置，占用多倍的存储空间。

## 清理缓存

::message{level=warning}
此段落功能仍在开发中。
::

manifest.json 缓存仅在当天有效，且 MCLI 每次尝试使用 manifest.json 时都会清理过期缓存。想要主动更新的话，使用命令
[minecraft manifest](../2.command/3.minecraft.md#manifest-命令) 即可。

文件下载缓存需要使用 cache 命令族管理。

作为缓存占用存储空间的参考，Minecraft Java 26.1 的资源文件和库文件缓存的总量在 500MiB 左右。
