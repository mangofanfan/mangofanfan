## 概念

环境变量是在系统和 shell 会话层面设置的变量。MCLI 的一些行为可以通过环境变量来控制。

* 行为开关：
  * `MCLI_ENABLE_LOG_OUTPUT` - 启用日志级别的终端输出。
  * ~`MCLI_SKIP_ONLINE_AUTH` - 跳过正版验证。~
  * `MCLI_NO_PROXY` - 忽略环境变量中的代理设置（`HTTP_PROXY`）。
  * `MCLI_NO_SSL_VERIFY` - 跳过下载文件时的 SSL 验证。
* URL：
  * `MCLI_MC_GAME_VERSION_MANIFEST_V2_JSON` - 获取 Minecraft 版本信息的端点。
  * `MCLI_MC_GAME_DOWNLOAD_LIBRARIES_URL` - 下载 Minecraft 的依赖库文件的基准 URL。
  * `MCLI_MC_GAME_DOWNLOAD_ASSETS_URL` - 下载 Minecraft 的资源文件的基准 URL。
  * `MCLI_MC_GAME_DOWNLOAD_VERSIONS_URL` - 下载 Minecraft 的游戏本体的基准 URL。
  * `MCLI_FORGE_PROMOS_URL` - 获取 Forge 标记版本信息的端点。
  * `MCLI_FORGE_DOWNLOAD_LIBRARIES_URL` - 下载 Forge 的依赖库文件的基准 URL。
  * `MCLI_FABRIC_META_VERSIONS_V2_URL` - 获取 Fabric 版本信息的端点。
  * `MCLI_FABRIC_DOWNLOAD_LIBRARIES_URL` - 下载 Fabric 的依赖库文件的基准 URL。

MCLI 会读取所在 shell 会话的变量，shell 中的变量继承自系统变量。不过，在系统变量中添加 MCLI
的变量并不是好主意。能够实现以上同等功能的 MCLI 配置系统正在计划中。

## 示例

### 在 shell 会话中设置环境变量

在 shell 会话内设置的环境变量仅在当前会话有效。

对于 PowerShell，这样设置环境变量。

```powershell
$env:MCLI_ENABLE_LOG_OUTPUT = "true"
```

对于 bash，这样设置。

```shell
export MCLI_ENABLE_LOG_OUTPUT="true"
```

### 使用 .env 文件设置环境变量

::message{level=warning}
可能存在安全风险，因为 `.env` 文件可能会被恶意写入。
::

MCLI 目前会自动读取工作目录下的 `.env` 文件，并应用其中的环境变量。此行为以后会更改，并伴随配置系统更新。

下面的「使用 BMCLAPI 作为镜像下载源」就是写入 `.env` 文件以实现设置环境变量。

### 使用 BMCLAPI 作为镜像下载源

```dotenv
MCLI_MC_GAME_DOWNLOAD_LIBRARIES_URL="https://bmclapi2.bangbang93.com/maven/"
MCLI_MC_GAME_DOWNLOAD_ASSETS_URL="https://bmclapi2.bangbang93.com/assets/"
MCLI_MC_GAME_DOWNLOAD_VERSIONS_URL="https://bmclapi2.bangbang93.com/"
MCLI_FORGE_DOWNLOAD_LIBRARIES_URL="https://bmclapi2.bangbang93.com/maven/"
MCLI_FABRIC_DOWNLOAD_LIBRARIES_URL="https://bmclapi2.bangbang93.com/maven/"
```

URL 末尾的斜杠不允许省略。
