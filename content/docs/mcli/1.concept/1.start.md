## 简介

MCLI 是一个使用 Python 实现的命令行工具，用于在任何位置构建可运行的 Minecraft Java 任意版本实例。

请注意，MCLI 目前还不是一个 Minecraft 启动器，你仍然需要一个启动器来运行已安装的游戏实例。

## 安装

### 安装 uv

MCLI 需要使用 uv 来运行。

uv 简单来说是一个 Python 包和环境管理器，您可以将其类比为 npm。在已安装 uv 后，您便可以简单地使用 MCLI。

#### 使用安装脚本（推荐）

在 Windows 上，使用 PowerShell 安装。

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

MCLI 还没有针对 Linux 和 macOS 系统开发和测试，但 uv 也可以在 Linux 和 macOS 上使用。

#### 使用包管理器

```shell
pipx install uv
```

```shell
pip install uv
```

```shell
winget install --id=astral-sh.uv  -e
```

```shell
scoop install main/uv
```

#### 编译安装

编译安装 uv 需要 Rust 工具链和一段比较长的等待时间。

```shell
cargo install --locked uv
```

更多与更详细的安装说明，请参见：<https://docs.astral.sh/uv/getting-started/installation/>

### 使用 MCLI

```shell
uvx mmccli --help
```

::message{level=fan}
MCLI 的命令名称是 `mmccli`，这是因为 `mcli` 在 PyPI 上已重名。

你可以认为 `mmccli` 是 Mango Minecraft Command-Line Interface 的意思。
::

`uvx` 命令来自 uv，允许你在临时环境中下载并运行 MCLI。你也可以选择将 MCLI 安装到您的系统中，以避免每次启动后首次使用时都要等待下载和安装。

```shell
uv tool install mmccli
# 然后……
mmccli --help
```

没错！作为 uv 工具安装后，你便不再需要 uvx 前缀来运行 MCLI 了。其中逻辑可以类似于 npx 和 `npm install -g`。

::message{level=fan}
所有命令都不区分 `uvx mcli` 和 `mcli` 方式，运行结果都是等价的。
::

## 快速上手

### 构建原版版本

您可以使用以下命令构建一个原版游戏。

```shell
mmccli add --minecraft 26.1
# 等价写法
mmccli add -mc 26.1
```

这会在**当前目录**下创建 `.minecraft` 目录，在其中构建 Minecraft Java 26.1 版本。如果已有 `.minecraft` 目录，MCLI
会复用它，并视情况复用一些相同的资源（如有的话）。

你也可以使用 `latest-release` 和 `latest-snapshot` 来指定最新的正式版和快照版。

```shell
mmccli add --minecraft latest-release
mmccli add --minecraft latest-snapshot
```

### 构建模组版本

要安装带有 Forge 加载器的游戏，你可以使用以下命令。

```shell
# 如果想要指定版本
mmccli add --minecraft 26.1 --forge 64.1.4
# 或者指定 Latest 和 Recommended 版本
mmccli add --minecraft 26.1 --forge latest
mmccli add --minecraft 26.1 --forge recommended
```

Forge 的 Recommended 和 Latest 是根据 MC 版本标记的。有的 MC 版本只标记了 Latest 而没有
Recommended，此时会静默回退到 Latest。

Forge 会静默完成安装，静默安装工具来自
[bangbang93/forge-install-bootstrapper](https://github.com/bangbang93/forge-install-bootstrapper)。

### 命名版本

MCLI 会自动根据 Minecraft 实例的本体版本、安装的模组加载器类型和版本（如有）命名已构建的游戏实例。

但如果你是整合包作者，或者出于一些特殊目的，你可能会需要在安装时显式地为游戏实例命名。

```shell
mmccli add --minecraft 26.1 --name "Mangoes Happy Life v1" --forge
```

::message{level=warning}
被命名的版本会启用版本隔离，此默认行为不可更改。
::
