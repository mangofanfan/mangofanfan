## 概念

配置系统允许你控制 MCLI 的一些行为。配置系统的取值来源依次为：命令行选项、环境变量、配置文件、默认值。

以环境变量举例，以下环境变量会被 MCLI 读取并应用。

* 行为开关：
  * `MCLI_LOG_LEVEL` - 设置日志级别（`DEBUG`、`INFO`、`WARNING`、`ERROR`）。
  * `MCLI_NO_PROXY` - 忽略环境变量中的代理设置（`HTTP_PROXY`）。
  * `MCLI_NO_SSL_VERIFY` - 跳过下载文件时的 SSL 验证。
  * `MCLI_EDITOR` - MCLI 打开配置文件时使用的代码编辑器。
* URL：
  * `MCLI_MINECRAFT_DOWNLOAD_LIBRARIES_URL` - 下载 Minecraft 的依赖库文件的基准 URL。
  * `MCLI_MINECRAFT_DOWNLOAD_ASSETS_URL` - 下载 Minecraft 的资源文件的基准 URL。
  * `MCLI_MINECRAFT_DOWNLOAD_VERSIONS_URL` - 下载 Minecraft 的游戏本体的基准 URL。
  * `MCLI_FORGE_DOWNLOAD_LIBRARIES_URL` - 下载 Forge 的依赖库文件的基准 URL。
  * `MCLI_FABRIC_DOWNLOAD_LIBRARIES_URL` - 下载 Fabric 的依赖库文件的基准 URL。

使用 `mmccli --help` 并在 Config options 栏目中查看这些设置选项。

同一配置项在不同来源的命名是有迹可循的。例如，日志级别在环境变量中的名称是 `MCLI_LOG_LEVEL`，在命令行选项中名为
`--log-level`，在配置文件中的键名为 `log-level`。

## 示例

### 在 shell 中设置环境变量

在 shell 会话内设置的环境变量仅在当前会话有效。

对于 PowerShell，这样设置环境变量。

```powershell
$env:MCLI_ENABLE_LOG_OUTPUT = "true"
```

对于 bash，这样设置。

```shell
export MCLI_ENABLE_LOG_OUTPUT="true"
```

### 使用 .env 文件设置环境变量

::message{level=warning}
开发版本的 MCLI 会自动读取工作目录下的 `.env` 文件，正式版本不会。也就是，从 PyPI 获取的 MCLI 不会。

读取陌生的 `.env` 文件可能存在安全风险，请仅读取受信任的环境变量文件。
::

例如使用 BMCLAPI 接管默认的官方下载源，可以编写如下的环境变量文件。

```dotenv [.env]
MCLI_MINECRAFT_DOWNLOAD_LIBRARIES_URL="https://bmclapi2.bangbang93.com/maven/"
MCLI_MINECRAFT_DOWNLOAD_ASSETS_URL="https://bmclapi2.bangbang93.com/assets/"
MCLI_MINECRAFT_DOWNLOAD_VERSIONS_URL="https://bmclapi2.bangbang93.com/"
MCLI_FORGE_DOWNLOAD_LIBRARIES_URL="https://bmclapi2.bangbang93.com/maven/"
MCLI_FABRIC_DOWNLOAD_LIBRARIES_URL="https://bmclapi2.bangbang93.com/maven/"
```

对于自动读取环境变量的开发版本，上列文件足以。

而对于正式版本，你需要自行在运行 MCLI 前将 `.env` 中的环境变量读取到 shell 会话中。一般来说，配置文件会是更好的选择。

### 使用 config 命令族更改 MCLI 配置

[mmccli config set](../2.command/5.config.md#set-命令) 命令可以一次一条地设置 MCLI 配置项。

```shell
mmccli config set minecraft-download-libraries-url "https://bmclapi2.bangbang93.com/maven/"
mmccli config set forge-download-libraries-url "https://bmclapi2.bangbang93.com/maven/"
mmccli config set fabric-download-libraries-url "https://bmclapi2.bangbang93.com/maven/"
```

### 使用 mmccli.toml 配置文件

此文件位于 `~/.config/mmccli/mmccli.toml`，也可能还未生成。

你可以使用 [mmccli config edit](../2.command/5.config.md#edit-命令) 命令打开该文件。如果你需要完全复用他人提供的
MCLI 配置，这就很有用了。

```toml [mmccli.toml]
# mmccli/mmccli.toml
# see https://mango.js.cn/docs/mcli/concept/config

[mcli]
log-level = "INFO"

[minecraft]
download-libraries-url = "https://bmclapi2.bangbang93.com/maven/"

[forge]
download-libraries-url = "https://bmclapi2.bangbang93.com/maven/"

[fabric]
download-libraries-url = "https://bmclapi2.bangbang93.com/maven/"
```
