## 行为

add 命令会在当前工作 Minecraft 游戏目录中添加一个版本实例。

```shell
# 安装最新的原版游戏
mmccli add --minecraft latest-release

# 安装 26.1 Forge
mmccli add --minecraft 26.1 --forge recommended

# 命名
mmccli add --minecraft 26.1 --name "Mangoes Happy Life v1"
```

MCLI 会优先更新缓存，查找版本信息，然后配合缓存下载剩余项。这可以在同一台机器上优化多次安装游戏的速度。即使安装不同版本，后续安装的速度也会有所提升。

关于 MCLI 的缓存行为，请参见[缓存行为](../1.concept/3.cache.md)。

## 参数

### --minecraft

**必须**。

你需要此参数来指定安装哪一个版本的 Minecraft，对吧？

除了版本号之外，还支持 `latest-release` 和 `latest-snapshot` 指代最新的正式版和快照版。

```shell
# 安装最新的快照版
mmccli add --minecraft latest-snapshot

# 安装指定的快照版
mmccli add --minecraft 26.4-snapshot-5
mmccli add --minecraft 22w07a

# 效果和用法完全相同的简写
mmccli add -mc 26.1
```

::message{level=warning}
MCLI 不支持下载 1.0 以前的 alpha 和 beta 版本，未来也不考虑支持这些版本。
::

你可以使用下面的一些参数来安装模组加载器，如 Forge 和 Fabric。请注意你只能同时安装一个模组加载器，即*可选但唯一*。

### --forge

**可选但唯一**。

你可以在安装 Minecraft 版本时一同安装 Forge 加载器。

除了 Forge 版本号之外，还支持 `recommended` 和 `latest` 指代推荐版本和最新版本。

请注意，`recommended` 和 `latest` 是由 Forge 团队为每个 MC 版本标记的特殊 Forge 版本，有的 MC 版本只有 `latest`
而没有 `recommended` 标记。如果指定 `recommended` 但该 MC 版本没有 `recommended`，MCLI 会回退到 `latest`。

```shell
# 安装 26.1 Forge 推荐版
# 由于 26.1 没有标记 recommended，所以最终安装的是 26.1 的 latest 版本 62.0.9
mmccli add --minecraft 26.1 --forge recommended

# 或者指定安装 Forge 版本
mmccli add --minecraft 1.21.11 --forge 61.2.4
```

安装 Forge 版本时，MCLI 会实际上添加两个版本，一个是原版，一个是 Forge 版。这是受 Forge 的安装流程限制。你可以在启动器中打开安装的 Minecraft 目录以验证。

如果同时提供 `--name` 参数，那么 Forge 版本会被重命名。

::message{level=warning}
MCLI 不支持为 1.13 以下的 Minecraft 版本安装 Forge，因为 MCLI 仅实现了新版 Forge 的静默安装。

其实是 <https://github.com/bangbang93/forge-install-bootstrapper> 实现的。
::

### --fabric

**可选但唯一**。

你可以在安装 Minecraft 版本时一同安装 Fabric 加载器。

除了 Fabric 版本号之外，还支持 `latest` 指代最新版本。Fabric 没有标记稳定版本一说。

```shell
# 安装 26.1 Fabric latest
mmccli add --minecraft 26.1 --fabric latest
```

安装 Fabric 版本时，只会增加一个 Fabric 版本。你可以使用 `--name` 参数命名这个版本。

### --name

**可选**。

你可以指定安装的 Minecraft 版本的名称。

这会作用于 `.minecraft/versions/<name>/<name>.json`，并支持在启动器中显示。

```shell
mmccli add --minecraft 26.1 --name vanilla-261

# 如果名称包含空格，请添加引号
mmccli add --minecraft 26.1 --name "Mangoes Happy Life V2"

# 模组版本也支持
mmccli add --minecraft 26.3 --forge latest --name forge-263
mmccli add --minecraft 26.3 --fabric latest --name fabric-263
```
