## size 命令

size 命令可以获取当前的全局文件下载缓存情况，返回各类型缓存的大小。

```shell
mmccli cache size
```

命令会分类输出不同类型的文件缓存数量和占用空间。你可以据此使用 `clean` 命令释放某一类的缓存。

## clean 命令

clean 命令可以清除下载文件缓存，以释放存储空间。可以接收复数个可选参数以指定清理的缓存类型。

```shell
# 只清理资源文件缓存
mmccli cache clean assets

# 清理依赖库文件和 Forge 安装器缓存
mmccli cache clean libraries forge-installer

# 好麻烦，全部清掉算了
mmccli cache clean
```

::message{level=info}
如果 MCLI 成功使用**硬链接**安装过游戏实例，那么清除缓存可能无法释放预期的存储空间。
::
