## 行为

::message{level=danger}
MCLI 未通过 [Mojang 的审核](https://help.minecraft.net/hc/en-us/articles/16254801392141)，因此 login 命令暂时无法使用。
::

login 命令会使用微软的设备流模式（Device Flow）完成至 Mojang 身份验证服务的 Oauth
登录。在验证您拥有 Minecraft Java 版游戏之后，MCLI 可以让您以在线模式启动游戏。

```shell
mmccli login
```
