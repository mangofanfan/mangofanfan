## 任何时候，通过命令选项设定配置

在运行任何 MCLI 命令时，你都可以使用一些设置选项来修改 MCLI 配置。这种行为严格来说不属于 config
命令族的功能，但的确息息相关。

```shell
# 设置选项必须紧跟在 mmccli 之后、任何子命令之前，可以有多个。
mmccli --log-level DEBUG config list
mmccli --no-ssl-verify --no-proxy config list

# 在 Config options 分组中查看所有设置选项。
mmccli --help
```

所有合法的配置键可在 [配置系统](../1.concept/4.config.md) 中查看。

## list 命令

list 命令会列出当前生效的全部 MCLI 配置项目。

即使未曾通过任何手段设置过，每个配置项也都会拥有默认值。

```shell
mmccli config list
```

在命令输出中，配置键的值的类型也会被标注，例如 `log-level` 的值的类型是一个枚举类，拥有 `DEBUG`、`INFO`、`WARNING`
和 `ERROR` 四个枚举值。

## set 命令

set 命令允许将一个配置项写入配置文件，配置文件会保存在 `~/.config/mmccli/mmccli.toml`。

此命令接收两个参数，分别是配置键的名称和配置值。`True` 和 `False` 会被转为运行时布尔值，枚举类型也会特殊处理。

```shell
mmccli config set log-level INFO
```

## edit 命令

edit 命令会使用*预先配置的代码编辑器*打开位于 `~/.config/mmccli/mmccli.toml` 的配置文件。如果该文件还不存在，MCLI
会先创建它，然后再打开它。

```shell
mmccli config edit
```

使用配置键 `editor` 来设置使用的编辑器，例如 `code` / `code.cmd`。如果未配置（`#default`），会从环境变量
`VISUAL` 和 `EDITOR` 至 `notepad.exe` / `vi` 依次回退。
