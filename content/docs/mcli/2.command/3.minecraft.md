## manifest 命令

重建 manifest.json 缓存，从 API 拉取新的 manifest.json。

```shell
mmccli minecraft manifest
```

MCLI 对 manifest.json 的缓存仅在当天有效，过期会立即弃用并删除。因此除非 Mojang
在一分钟前发布了新版本，否则你无需使用此命令。

其他命令例如 [add](2.add.md) 会优先尝试使用 manifest.json 缓存。如果缓存使用失败，则从 API 拉取新的
manifest.json，此部分的行为与本命令完全一致。

## list 命令

列出 Minecraft 的已发布版本。

```shell
# 默认行为：列出所有版本类型，列出 20 个版本条目
mmccli minecraft list

# 指定版本类型和条目数量
# 条目数量为 0 表示不限数量，全部列出
mmccli minecraft list --type release --limit 5
```

版本类型的允许值有 `all`、`release` 和 `snapshot`。

::message{level=info}
MCLI 目前不支持类型为 `old_alpha` 和 `old_bata` 的版本，也不考虑支持这些早期版本。MCLI 支持从 1.0 开始的所有版本，包括愚人节版本（被视为快照版本）。
::
