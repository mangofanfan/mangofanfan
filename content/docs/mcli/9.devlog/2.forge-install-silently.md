## Forge 安装器格式

Forge 安装器中存在 `version.json` 和 `install_profile.json` 两个清单文件。

### 注释

首先，在这两个文件的第一个键中，Forge 声明了以下内容：

> Please do not automate the download and installation of Forge.
> 
> Our efforts are supported by ads from the download page.
> 
> If you MUST automate this, please consider supporting the project through <https://www.patreon.com/LexManos/>

> 请不要自动化 Forge 的下载和安装。
> 
> 我们通过下载页面上的广告来获得收益。
> 
> 如果你 **必须** 要实现自动下载和安装，请考虑在 <https://www.patreon.com/LexManos/> 支持我们的项目。

所以如果 MCLI 能够产生收益的话，其一部分将会被用于支持 Forge。除此之外，还有 BMCLAPI 等其他项目也需要支持。

那是以后的计划了。

### 库文件

在这两个清单文件中都存在 `libraries` 键，其中存有一些库文件。

有理由相信 `version.json` 中的库文件是游戏运行时需要的，`install_profile.json` 中的库文件就可能是 Forge
安装器需要的。总之都要下载就对了。

所以 MCLI 需要解包 Forge 安装器，提取这两个清单文件，然后提前将所需库文件下载完毕。否则，这些库文件将由 Forge
安装器进行下载，无法切换镜像下载源，也保证其下载速度。

### forge-client.jar 文件

这是一个特殊的库文件，位于 `version.json` 的库文件清单的第二个。该库文件不提供 url，因此无从下载。

```json
{
  "name": "net.minecraftforge:forge:26.3-66.1.0:client",
  "downloads": {
    "artifact": {
      "path": "net/minecraftforge/forge/26.3-66.1.0/forge-26.3-66.1.0-client.jar",
      "url": "",
      "sha1": "9581d4977f841f7ce33bde86954d586981a30c5b",
      "size": 82957733
    }
  }
}
```

即使通过 path 拼接 url 也无从下载，拼出来的地址会报 404。

此库文件需要由 Forge 安装器对 Minecraft 本体进行处理后得到，处理步骤在安装过程中进行，安装器还附带一个 sha1
值用于校验处理结果。处理之后的 Minecraft 本体就是 forge-client.jar。

由此可以相信，该文件不能预先提供的原因很可能是违反 Minecraft EULA。

## 静默安装

那么，通过 bangbang93 无私提供的 [Forge 安装器](https://github.com/bangbang93/forge-install-bootstrapper)，我们就可以很简单地实现 Forge 的下载和静默安装流程了。

1. 下载指定版本的 Forge 安装器；
2. 解压，提取两个清单；
3. 下载除了 forge-client.jar 之外的所有库文件；
4. 运行安装器，由于所需依赖均已下载，安装器会立刻开始安装；
5. 安装完成。

哦对了，MCLI 还需要实现 `launcher_profiles.json` 文件，这是官方启动器的配置文件，PCL2 也会生成此文件。Forge
也使用此文件来校验 Minecraft 安装目录。

没有了，你已经学会实现 Forge 安装了。
