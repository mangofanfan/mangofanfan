## 扩展简介

:link-github-card{name="MCFPP-vscode-extension" url="https://github.com/mangofanfan/MCFPP-vscode-extension"}

该扩展为 :term-tip-vscode 提供了对 :term-tip-mcfpp 语言的支持。

### 安装

从 :term-tip-visual-studio-market 下载 VS Code 扩展。

[MCFPP](https://marketplace.visualstudio.com/items?itemName=MangoFanFanw.mcfpp)

或者，在 VS Code 的扩展市场中搜索 `MCFPP` 即可。

扩展的官方图标如下所示。

:fan-image-icon{src="MCFPP-icon.png"}

### 功能

已经实现的功能：

* 基于 TextMate 的基础语法高亮；
* 由 :term-tip-lsp 实现的语义高亮、智能补全和错误警告；
* 函数文档渲染。

![函数文档](mcfpp/function-doc.png)
