这是芒果客栈的隐私政策。当前版本为 2026 年 10 月 16 日更新的第 1 版。

## 关于芒果客栈

芒果客栈是部署在 :term-tip-cloudflare Worker 上的混合模式站点，其中整个前端部分均为静态部署并提供，`/api` 端点为动态提供服务。

芒果客栈是芒果帆帆的个人博客站点。

如果出于任何原因，您可以从以下电子邮件地址联系芒果帆帆：

* `fan@fanfan.moe`
* `mangofanfanw@icloud.com`

## 我们提供的服务

芒果客栈是一个半静态的博客网站，所有内容作为个人记录与项目文档所用，没有注册或登录入口，没有用户系统，不提供任何付费增值服务。

芒果客栈的“在线小玩具”是一批基于浏览器和/或 Cloudflare Worker 工作的在线工具，芒果客栈不为这些“在线小玩具”的可用性和稳定性担保。

芒果客栈的一些页面拥有评论系统，您无需登录即可留言评论，评论会展示给其他访客。在提交评论后，您就无法自助修改或删除评论。您可以与芒果客栈联系以对评论请求操作。芒果客栈也会主动隐藏或删除不符合芒果客栈守则的评论。

## 我们收集的信息

芒果客栈不主动收集任何与您个人相关联的信息。芒果客栈没有使用任何统计脚本，比如 Google Analytics。

芒果客栈使用 Cloudflare CDN 保障本网站的正常运行、提升页面访问速度并防范网络攻击（如 DDoS
攻击和恶意爬虫）。当您访问本网站时，您的网络流量将通过 Cloudflare 进行路由。在此过程中，Cloudflare
会自动收集并处理特定的技术信息，包括但不限于您的 IP 地址、浏览器类型、操作系统、访问日期与时间以及网络请求的元数据。这些数据由
Cloudflare 收集，其处理方式也由 Cloudflare 决定，[您可以在这里查看 Cloudflare
的隐私政策](https://www.cloudflare.com/zh-cn/privacypolicy/)。

芒果客栈使用 Cloudflare Turnstile 以验证您的评论，Turnstile 会收集您的浏览器指纹等信息以用于验证。[您可以在这里查看
Turnstile 的隐私政策](https://www.cloudflare.com/zh-cn/turnstile-privacy-policy/)。Turnstile
仅在您“启用评论表单”时开始工作，所以如果您不进行评论，那么 Turnstile 不会触发。

芒果客栈使用 Cravatar 初认头像对评论提供头像，头像基于评论时留下的电子邮件地址获得。如果您留下评论，您的头像会先后尝试从
Cravatar、QQ、Gravatar 三个来源获取，并回退到默认头像。[您可以在这里查看 Cravatar 的隐私政策](https://cravatar.com/privacy/)。

## 我们存储的信息

以下信息被存储在您的浏览器中，这些信息为优化您的浏览体验而存储，与您的个人信息无关。我们也不会获得这些信息。

* 偏好主题（`light`、`dark`），位于 LocalStorage 中。

Cloudflare CDN 和 Turnstile 可能会在您的浏览器中存储必要的 cookie 等信息以用作访问验证，这些数据一般是临时性的，会在您关闭页面或浏览器时清除。

### 评论

在您的评论提交之后，评论数据会被持久化存储在 Cloudflare D1 中，每条评论仅包含您在表单中显式提供的信息，具体来说是：

```json {5-8}
{
  "id": 6,
  "userId": 0,
  "parentId": 0,
  "name": "your name or something here",
  "email": "example@mango.js.cn",
  "link": "https://example.mango.js.cn/",
  "content": "Your comment's content is here.",
  "createdAt": "1792126245",
  "route": "/path/to/a/page"
}
```

请注意，虽然并不建议这种行为，但是您确实可以提供并不与您关联的电子邮件地址、名称和在线链接并提交评论。在 Turnstile
验证通过后，芒果客栈不会对字段进行额外校验。

请注意，您在评论时留下的电子邮件地址仅用于从 Cravatar 头像服务获取与您关联的头像，而不会在芒果客栈公开展示。

评论信息会不限期地永久储存，但如果评论存在违反芒果客栈守则的情况，芒果客栈保留在不经通知的情况下隐藏或删除评论的权力。

提交评论视作您已同意芒果客栈关于您的评论信息的以上处理方式。

### 您的权利

由于静态站点的必然限制，芒果客栈无法在页面中为您提供编辑、删除评论的功能入口。您可以与芒果客栈直接联系以寻求删除评论，请使用您在评论时留下的电子邮件地址发送邮件至芒果客栈，以证明您对该评论的所有权。

您可以诉求将评论删除，芒果客栈会从 Cloudflare D1 中删除该评论，其他访客将不再能看见您的评论。

Cloudflare D1 拥有回滚功能，某种意义上您的评论仍然可以被找回，但芒果客栈不接受找回已删除的评论的诉求。
