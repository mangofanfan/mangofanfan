## 投着玩

Alen 从今年的上半年开始就用休闲时间混迹于 Boss 直聘这一招聘软件，本着广撒网的理念坚持至今投递出八百多份简历。上半年时还是 Java 后端岗，下半年就转至了 Agent 开放岗。

Alen 说自己这只是投着玩。

我怎么看不出来只是投着玩，谁没事拿投简历当玩啊。

只是我没有想到他真的准备实习。暑假的时候找了一个在南京的实习，为此租了两个月的房子，工资不够付房租。而且应该还是摊上了奇妙的老板，喜欢喝富氢水，整了一台坏掉的富氢水饮水机放在公司，因为坏掉了所以我没能成功让 Alen 带点过来请我喝。

这倒也能理解。只是开学后，Alen 回到学校上着课，开始投递 Agent 开发岗的简历，然后在 9 月中旬前往北京就职。在就职之前，他还在面试各家企业，有大有小。

## 诡异的氛围

本科结束之后无非两个方向，考研继续读，或者找工作直接就业。

我们宿舍存在一位年纪排名数一数二的角色，好叭其实应该就是第一。

第一在宿舍里毫无疑问是健谈的，他肯定是读研并且目标是更好的学校。他只是太健谈了，会替别人考虑别人的未来，比如催他隔壁床的室友认真点学试试保研或者冲更好的学校，然后催 Alen 赶紧找大企业的实习，然后催我赶紧开始投简历。

我成绩是不怎么好，我也没怎么上心，我要是能上心学习的话我就不会在南邮了，多加一分我都不在了（笑）。所以毫无疑问是直接就业，但是那也不至于在课还很多的时候就把课翘了从南京跑到北京去实习吧？

学校让我们想实习的在寒暑假去找。这意味着寒暑假时期的激烈岗位竞争，以及学期内的岗位富余。但是不管怎么说，课我平时可能不高兴就不会上，但是让我直接白天出去实习，甚至是直接去外地偷偷实习，感觉都是很…奇怪的事情。

但是为什么好像大家都很推崇并且打算这样做呢……

## 如果你决定漂向北方

不过，你已经决定漂向北方，我无力改变你深思熟虑之后的决定。

我没有收入，没有工作，有上不完的课，签不完的到。

你的床位上没有了一个身影，你的桌上不见了一台出风口可以煎鸡蛋的笔记本电脑。

但你终究还会回来，而我会一直在等你。
