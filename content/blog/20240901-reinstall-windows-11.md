昨天（2024 年 8 月 31 日）给跟了我五年的电脑重装了个系统，联想拯救者，Windows 11。

其实没什么好特地介绍的，就是说大概记一下流程啥的吧……

## 前情提要

首先，我的笔记本由于我本人的瞎折腾，已经在 Windows 预览成员体验计划里呆了几年了我也不知道，这样导致的一个问题就是：
为了执行 Windows 全新安装，我将不得不安装一个正式版 —— 比我电脑此刻的版本要旧的版本。

因此，所有的用户数据将无法保留，电脑数据将重置到出厂状态。虽然这台电脑出场的时候是 Windows 10 啦……

数据和存储是两个概念，我们放在 D、E 盘中的存储是不会清空的，而系统盘 C 盘由于是系统盘，所以存储的东西可能会丢得有点惨重，因此我们要先准备好。

## 准备工作

我细细思索，发现好像没什么值得我特地保存的特别重要的文件。

* 用 Pycharm 写的芒果工具箱一直是推送到 :term-tip-github 仓库的，只要在开干前再推送一次全部更改就可以了。
* Steam 游戏库是在 D 盘、E 盘各放了一份，C 盘空间稀缺所以没有安装在 C 盘的游戏，不用管。
* 《我的世界：地下城》的存档，需要在更新之前上传保存一下，因为这个游戏不会自动进行云存储，保存之后问题不大。
* 系统存储的所有通行密钥都将丢失，不过有手机在手，重新登录这些网站也不是什么大问题。

## 开干！

### 制作系统安装盘

根据微软官方的帮助文档，我们需要将 Windows 安装程序安装到一个外部存储设备（U 盘或 DVD），我选择一个 U 盘。

* 这个 U 盘需要足够的存储空间，实际上安装程序占据了 7~8G 左右，我的 U 盘还剩下 22G 的储存空间。
* 制作安装盘的过程会清空 U 盘内所有已经存在的文件，我建议先把 U 盘手动清空或格式化。
* [微软提供了软件](https://www.microsoft.com/zh-cn/software-download/windows11)。

使用下载页面的第一个按钮下载 Windows 11 安装助手，并在电脑上连接你准备好的外部存储设备（我是 U 盘），运行安装助手，它将花一段时间为你制作 Windows 11 安装盘。

这段过程需要联网，因为这么小的安装程序不可能把 8G 的系统压缩进来，对吧？

这段时间我是用来清理硬盘空间的，毕竟电脑的三个盘都快炸了，这能忍……

### 安装前须知：正版

如果你的设备是「笔记本电脑」，随机附赠 Windows 正版的那种，那么重新安装 Windows 之后，Windows 将自动激活。

原理：Windows 正版凭证被录入到主板上，激活会自动进行。而 Windows 10 和 11 的激活凭证是可以共用的，因此出厂时的 Windows 10 本也可以自动激活 11。

但是 Office 套件（Microsoft Office）是跟随微软账户的，我的电脑那个年份出厂附赠的是 Office 家庭和学生版 2019，那么重装之后就必须要安装 Office 2019，并用五年前激活 Office 使用的微软账户再登录一次 Office 的任意软件（Word、PPT、Excel 等之一），以完成激活。

完成激活之后，Office 2019 在此设备上就完成激活，可以更换其他的微软账户登录 Office，哪怕把激活用的五年前的账户从设备上删除也不会影响 Office 的激活状态。

你也可以使用其他手段激活 Office，在此略过。

### 运行安装程序

准备完毕后，打开 U 盘根目录，运行 setup.exe，开始安装流程。

基本上是傻瓜式，设备将重启几次，花上一段不少的时间，然后开始安装流程，你将可以看到全新的 Windows 11 安装界面（我反正从来没见过，第一次见感觉还蛮别致的，但是我可不想经常见这个界面）。

安装界面会需要你提供一些信息，例如这台设备的新名字、地区和语言、是谁（哪个微软账户）将要使用、是否是家庭设备（即需要在多个微软账户之间切换）等等。如果设备连接了宽带光纤，则不需要提供可用的无线局域网连接。

然后，我们将获得一个崭新的 Windows 桌面。

### 暴风安装程序

打开 Microsoft Store，我们将要在新设备上安装那些曾经安装的程序。

不得不说如今的微软官方应用商店已经比过去完善了许多，全新的桌面版 QQ、Bilibili、火绒、WPS、微信输入法都可以在上面找到，还有一些宝藏软件比如 MagicPods，以及微软买下的游戏比如 Minecraft。如果要玩游戏的话，XBox 似乎默认安装了，但是 NVIDIA 的控制面板居然没有，而且商店里的 NVIDIA 控制面板安装不了（点击安装按钮无反应），只能去官方下载。

还有一些软件仍然需要从浏览器下载，比如企业微信，比如米哈游启动器，比如 JetBrains 的 Tool Box 和 IDE。

还有你猜我的 Office 2019 是从哪边下载的，是 [Office Tool Plus](https://otp.landian.vip/zh-cn/)，微软你坏事做尽，自家商店只提供 Microsoft 365！

## 后记

念叨了一个暑假都没想着重装系统，昨天突然决定的原因很简单，忍不了了。

不知道是哪个小流氓软件篡改了我的 Windows 设置应用程序，好多设置项凭空消失了。对付应用程序异常的方法是通过 Windows 设置重置或修复该应用程序，但是很遗憾，我的 Windows 设置中的应用程序列表已经没了，无效。

既然如此，干脆重装算了。QAQ
