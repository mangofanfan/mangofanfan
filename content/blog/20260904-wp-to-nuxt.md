芒果帆帆的个人网站（曾用名：芒果帆帆的破站）正在从 :term-tip-wordpress 搬迁至 :term-tip-nuxt ！

::message{level="info"}
搬迁仍在进行中！新的网站也仍在建设中！
::

## 动机

### 新的尝试

因为芒果想要尝试一些新的东西，比如，让手头的 mango.js.cn 域名重放光芒，而不是只能作为一个 :term-tip-cloudflare
局域网穿透的自定义域名。

如你所见， :term-tip-nuxt 其实并非一个和 :term-tip-wordpress 同类型的东西。准确地说，此站点现在是一个由芒果帆帆使用
:term-tip-nuxt 自行设计与搭建的纯静态站点。

也就是说，你所看见的此网站上的每一寸像素，都是由芒果亲自放置的，而非从网上找来了一个什么主题！

### 新的需求

随着时间的推移，芒果拥有越来越多的各种「项目」可以推进。虽然其中很大一部分都已被抛之脑后，或者被放在硬盘 /
:term-tip-github 仓库 / ... 当中落灰。

已有的 :term-tip-wordpress 博客可以通过文章记录这些项目，但是为 :term-tip-wordpress 写文章还是太累了。
尽管已经是一个成熟且足够友好的个人博客系统，还是太累了，而芒果是很懒的。

加上， :term-tip-wordpress 必然需要在服务器环境中部署，且随网站流量增大（真的会增大吗老师？），服务器也需要同步升级。
虽然芒果已经自诩会一点点 :term-tip-linux 和服务器运维，但终归还是头疼，一不小心……就会丢数据，让网站回档。

所以，芒果急需一个只要使用简单的 :term-tip-markdown
就能实现需求的，并且高拓展性的内容管理系统。高拓展性意味着，除了博客内容之外，一些其他内容也可以被简单地放置在网站上。

## 原理

:term-tip-nuxt 是一个 Web 全栈框架，其最大的特点是提供多种部署方式，包括
:term-tip-vue 原生的 :term-tip-csr ，也有一键生成静态站点的 :term-tip-ssg 。静态站点将避免昂贵的服务器开支与维护需求，
可以直接在 GitHub Pages 或者云服务商提供的存储桶中部署。

而在开发方面， :term-tip-nuxt 的开发体验和 :term-tip-vue 相比几乎一致。

这也就意味着，芒果可以完全地定制一个自己的静态站点，然后简单地将其部署。每一个组件都可以客制化，想想就非常得美味😋。

正巧这学期（大三上）有网络开发的课程，我倒要看看是老师更会网络开发还是我更会网络开发！（叉腰）

### 技术路线

* :term-tip-tailwindcss - 实现大部分的自定义样式；
* :term-tip-nuxt - :term-tip-ssg 部署的底层框架；
* Nuxt Content - 提供从 :term-tip-markdown 到静态页面的内容管理能力；

这一次，主要的待学习内容集中在 :term-tip-nuxt 中，大体也就是先开着翻译浏览一遍文档，然后扔到后台备用，没有什么很难的点。
